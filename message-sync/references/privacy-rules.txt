# 脱敏自检的自定义词表
#
# deny: 内部敏感词，整行包含即命中（组织名、产品名、客户名、集群名等）
# allow: @ 后接这些词时不算人名（泛指词，避免误报）
# 一行一条，# 开头为注释；同一行只取第一个匹配。

# ---- 泛指词（默认已内置一批，这里列出可自行增补）----
allow: 所有人
allow: 某人
allow: 成员
allow: 对象分块
allow: 人和截止
allow: 负责人
allow: 决策人
