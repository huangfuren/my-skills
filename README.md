## 说明

- 大多是给 AI 助手用的 skill（`SKILL.md` + `references/` 结构），按需维护。
- 每个 skill 一个子目录，目录内 `SKILL.md` 是入口。
- `dsh-plugin-dev/` 是一套**成套**的 skill 库（内含 10 篇 + 一份库级 `README.md` 与任务索引），
  与 `svg-diagram` 这类单篇 skill 不同，它自身再分一层子目录。
