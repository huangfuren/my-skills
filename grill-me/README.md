# grill-me

一个反复盘问你的方案或设计、直到每个决策都定下来，并把结论落成决策记录的 skill。

它不会一上来就写代码，也不会一次抛给你五个问题。它先复述对方案的理解请你确认，然后沿着决策树一次问一个问题，每问都带 2–4 个附了代价的选项。

当你想要压力测试一个方案、让人挑出设计里的漏洞，或者只是想听一句"拷问我"时，用它。

## 它和普通追问的区别

| | 普通追问 | grill-me |
| --- | --- | --- |
| 提问节奏 | 一次抛 3–5 个问题 | 一次一个，答完再问 |
| 提问形式 | 正文列表 | 多选弹窗，可点选可自填 |
| 提问顺序 | 按对话顺序 | 按"改起来最贵"排序 |
| 提问范围 | 想到哪问到哪 | 六维议程：范围/非目标、数据契约、失败路径、部署与回滚、验收标准、扩展口子 |
| 终止 | 问到没得问 | 8–12 问预算，用户喊停即停 |
| 产出 | 散在对话里 | 决策记录文件（含放弃的备选与待定项） |

## 安装

把整个目录放进你的 skills 目录：

```
<skills-dir>/grill-me/
├── SKILL.md
├── assets/design-decisions-template.md
└── README.md
```

对 DeepSeek Harness（dsh），skills 目录是全局的 `~/.dsh/skills/`，或仓库根的 `.dsh/skills/`（项目级）。把整个目录放进去，新开会话生效。

装好后说一句 "grill me"（或"拷问我""帮我压力测试这个方案"）即可触发。

## 依赖

- 宿主需要提供 `AskUserQuestion` 这类多选弹窗工具。若没有，该 skill 降级为纯文本提问，仍保持一次一问。
- 需要写文件的权限才能落盘决策记录；无权限时退化为对话内汇总。
