# 设计 token

色板、字阶、间距、阴影、缓动、断点全部来自 yjops.com.cn 构建产物
`index-BgxvFayx.css`（2026-10-27 逐条 grep 实测），不是目测。
**圆角阶梯例外**——那是归纳后的收敛值，与源站实际分布不同，差异见「圆角阶梯」一节。
改动时优先改本文件的表，再去改代码。

## 三条推导原则

1. **底色不纯白，正文不纯黑。** 降低对比到"清晰但不刺"，同时保留 11:1 以上的
   正文可读性。纯白页面在长文阅读时睫状肌持续紧绷，这是"累"的物理来源。
2. **颜色只承担一件事。** 一个强调色负责"点这里"，其余全部用中性灰阶表达层级。
   中性色阶用**冷灰**（带蓝倾向）而非暖灰——冷灰显理性、克制，暖灰显亲和但松散。
3. **本规范内部所有数值成阶梯，不出现孤值**：圆角 5 档、字阶 7 档、间距 4px 基数。
   出现 11px 圆角、13px 字距这类孤值时，页面会有说不清的"不齐"。
   注意这条是**收敛方向**，不是对源站的描述——源站圆角有 10 个取值，本身就带孤值。

## 色板

| `--soft` | `#edf1ff` | 激活项底、选中行、标签底 | — |
| `--ink` | `#273451` | 正文、标题 | 底上 11.55:1 ✓✓ |

| `--line` | `#e6eaf3` | 1px 描边、分隔线 | — |

### 对比度修正（源站未达标，建议在自建时改掉）

| 问题 | 现值 | 修正 | 修正后 |
|---|---|---|---|
| 主按钮白字 | `#6579ee` | 按钮底改 `#5063d6`（直接把 hover 色当常态） | 5.13:1 ✓ |
| 辅助文字 | `#66758e` | 提到 `#5a6880` | 5.26:1 ✓ |
| 小字元信息 | `#7a88a1` | 提到 `#66758e` 或加粗到 500 | 4.35:1 ⚠→✓ |

`#6579ee` 本身不必改——**作为标题关键词、图标、边框、焦点环使用完全合格**
（大字与图形只需 3:1）。要改的只是"白字压在它上面"的那一种用法。

## 字阶

只允许这 7 档，其余需求用 `clamp()` 在相邻档之间插值。

| 角色 | 字号 | 行高 | 字距 | 字重 | 备注 |
|---|---|---|---|---|---|
| 首屏 H1 | `clamp(38px, 4vw, 58px)` | 1.38 | `-0.035em` | 750 | 移动端降到 44 / 34 / 29 |
| 区块 H2 | `clamp(28px, 3vw, 40px)` | 1.5 | `-0.025em` | 700 | |
| 卡片 H3 | `18px` | 1.45 | `-0.02em` | 600 | |
| 导语 | `16px` | **1.95** | 0 | 400 | `max-width: 660px` |
| 区块说明 | `15px` | 1.9 | 0 | 400 | `max-width: 520px` |
| 正文 / 列表 | `14px` | 1.9 | 0 | 400 | |
| 元信息 / 标签 | `12px` | 1.7 | 0 或 `+0.1em` | 500 | 全大写或小标签时用正字距 |

规则：

- **负字距只给 24px 以上的标题**。正文用负字距会把笔画粘连，尤其"谢、豫、衡"这类多横字。
- **正字距只给全大写西文与小标签**（eyebrow）。中文加正字距会散架。
- 中文长句行宽控制在 **32–38 个汉字**（660px / 16px ≈ 37 字），超出就要换行或缩容器。

## 间距节奏

基数 4px，常用档位：

| 场景 | 值 |
|---|---|
| 区块上下内边距 | 52 / 56 / 60 / **64** / 76 / 80 / 90 px（默认取 64） |
| 区块之间无分隔线时 | 上 80 / 下 80，靠留白分区 |
| 标题与正文之间 | 24px |
| 段落之间 | 16px |
| 卡片内边距 | 20–24px |
| 按钮组间距 | 24px（移动端 18px） |
| 网格列间距 | 40px（桌面）/ 24px（平板）/ 12px（手机） |

首屏结构值（可直接照抄）：

```
.home-hero__inner   padding-block: 64px 40px;  gap: 44px;
.home-hero__copy    max-width: 900px;
h1                  margin: 24px 0;
lead                max-width: 660px; margin: 0 auto;
.hero-actions       gap: 24px; margin-top: 32px;
.hero-meta          gap: 16px; margin-top: 32px;
```

## 圆角阶梯

**推荐 5 档**（本规范取值，直接用这套）：

| 值 | 用途 |
|---|---|
| `8px` | 小标签、输入框内元素、kbd、浮层按钮 |
| `10px` | 按钮、分段控件、搜索框 |
| `14px` | 卡片、产品截图框 |
| `18px` | 大浮层、弹窗底部 |
| `24px` | 药丸标签（eyebrow）、chip |
| `50%` | 状态点、头像（圆形，不占档位） |

**源站实际分布**（`index-BgxvFayx.css` 逐条统计）：

| 值 | 次数 | 处理 |
|---|---|---|
| `14px` | 17 | 保留 |
| `8px` | 17 | 保留——与 14px 并列最高频，取代下面单独出现的 7px |
| `10px` | 13 | 保留 |
| `7px` | 10 | 并入 `8px`：1px 差异视觉不可辨，两值并存只制造不齐 |
| `12px` | 9 | 按元素大小归入 `10px` 或 `14px` |
| `6px` | 7 | 归入 `8px` |
| `9px` | 5 | 归入 `8px` 或 `10px` |
| `16px` | 4 | 归入 `14px` 或 `18px` |
| `5px` | 3 | 归入 `8px` |
| `4px` | 3 | 归入 `8px` |

源站一共 10 个取值，其中 5/6/9/16 属于孤值——这是它局部"不齐"的来源之一。
收敛成 5 档后观感只会更稳，不会偏离风格；要与源站逐像素一致时，用 `8px` 而非 `7px`。

原则：**元素越小、圆角越小**。给 24px 高的小按钮上 14px 圆角会变成胶囊，显得轻浮。

## 阴影

阴影只用透明度分层，不用颜色堆叠。

| 用途 | 值 |
|---|---|
| 卡片静置 | `0 16px 48px rgba(52, 75, 128, .063)` |
| 产品截图框 | `0 24px 70px rgba(83, 107, 179, .11), 0 3px 12px rgba(83, 107, 179, .04)` |
| 主按钮 | `0 5px 14px rgba(101, 121, 238, .145)` |
| 主按钮 hover | `0 7px 18px rgba(101, 121, 238, .196)` |

判断标准：把页面缩小到 50% 看，**阴影应该几乎看不见，但删掉后卡片会"陷"进底色**。
如果缩小时能看到一团灰雾，就是太重了。

## 缓动与时长

| 场景 | 时长 | 曲线 |
|---|---|---|
| 颜色、边框、底色 | `.15s` – `.18s` | `ease`（颜色变化用默认曲线即可） |
| 位移、缩放 | `.2s` – `.24s` | `cubic-bezier(.22, 1, .36, 1)` |
| 导航栏收起 / 展开 | `.32s` | `cubic-bezier(.22, 1, .36, 1)` |
| 弹层入场 | `.32s` | `cubic-bezier(.22, 1, .36, 1)` |

`cubic-bezier(.22, 1, .36, 1)` 的特征是**前 30% 走完约 70% 的距离，后 70% 时间在收尾**。
这是"高级感"最廉价也最有效的来源：位移起来不犹豫，停下不顿挫。

禁止 `transition: all`——它会把 `box-shadow`、`filter` 一起带上，长列表里造成掉帧。

## 断点与容器

| 断点 | 变化 |
|---|---|
| `1280px` | 三列网格收成两列 |
| `1080px` | 侧栏折叠，容器边距 40px |
| `900px` | 双栏变单栏，hero 居中 |
| `760px` | 导航收进抽屉，容器边距 32px，header 68px |
| `540px` | 按钮组换行，字阶进入最小档 |

容器宽度：

```css
--shell: min(1280px, calc(100% - 64px));
/* ≤1080px */ --shell: calc(100% - 40px);
/* ≤760px  */ --shell: calc(100% - 32px);
```

桌面固定 1280px 上限 + 左右 32px 留白，是"内容不贴边、也不至于在大屏上散开"的平衡点。
不要用 `max-width: 1200px` 配 `margin: 0 auto` 而不给移动端留白——小屏会贴边。

## 字体策略

源站写 `Inter` 打头但**不加载字体文件**，等于只有装了 Inter 的机器看得到，
其余回落 PingFang SC / 微软雅黑。

| 方案 | 代价 | 适用 |
|---|---|---|
| 零字体文件（源站做法） | 跨平台观感不一致，Windows 会显微软雅黑 | 内部工具、可接受 |
| 自托管 Inter + 思源黑体子集 | 首屏 +40–80KB，需 `font-display: swap` | 对外品牌站 |
| 只用系统栈 | 最稳、0 请求，观感随系统 | 大多数企业站，**推荐** |

推荐系统栈（去掉 Inter，避免"声明了却没有"的落差）：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

中文正文的中性字体选 **PingFang SC**（macOS）与 **微软雅黑**（Windows）时，
字重要比西文设计稿略降一档——微软雅黑在 400 时明显偏黑，同理 500 会接近 700。
