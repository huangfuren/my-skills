# 校验清单

**结构合法 ≠ 画面正确。** 两道关都要过：先校验 XML，再渲染目视。

## 一、校验与渲染命令

```bash
# 第一关：XML 结构合法性
python3 -c "import xml.dom.minidom; xml.dom.minidom.parse('images/xxx.svg'); print('SVG 结构合法')"

# 第二关：渲染成 PNG（macOS 自带 qlmanage，无需装依赖）
mkdir -p /tmp/svgchk && qlmanage -t -s 1500 -o /tmp/svgchk images/xxx.svg

# 打开 /tmp/svgchk/xxx.svg.png 目视检查（用图片查看工具，不要只看文件是否生成）

# 第三关：残留旧文案排查
grep -n "待确认\|待补录\|未记\|未知\|TODO\|【" images/xxx.svg || echo "无残留"

# 检查完清理
rm -rf /tmp/svgchk
```

`-s 1500` 是渲染宽度，图很宽时调大到 1960 看细节。

### 其他渲染方式（qlmanage 不可用时）

```bash
rsvg-convert -w 1960 xxx.svg -o /tmp/out.png     # brew install librsvg
magick -density 144 xxx.svg /tmp/out.png          # ImageMagick
python3 -c "import cairosvg; cairosvg.svg2png(url='xxx.svg', write_to='/tmp/out.png', output_width=1960)"
```

## 二、目视检查清单

渲染出 PNG 后逐项过，**不许跳项**：

### 文字

- [ ] 卡片内文字没有超出卡片边框（尤其长网段号如 `198.51.100.0/24`）
- [ ] 说明文字没有超出所在区块右边界
- [ ] 没有文字互相压盖
- [ ] 没有文字压在连线或箭头上
- [ ] 中文没有出现豆腐块（字体栈是否写全）

### 容器与布局

- [ ] 每个子元素都完整落在父容器内，没有溢出边框
- [ ] 区块之间没有互相压盖
- [ ] 画布底部没有裁掉内容（图例是否完整可见）
- [ ] 画布底部没有大片空白（`viewBox` 高度是否该收缩）
- [ ] 并列分区左右对称，高度和内部区块 y 坐标对齐
- [ ] 同排卡片宽度一致、间距均匀，没有一张歪出来

### 连线

- [ ] 箭头指向正确的目标，没有插进矩形内部
- [ ] 箭头颜色与线同色（marker 的 fill 与 line 的 stroke 一致）
- [ ] 双向箭头两端都有箭头（`orient="auto-start-reverse"` 写了没）
- [ ] 实线 / 虚线的语义正确：已确认用实线，待确认用虚线

### 内容正确性

- [ ] 图例条目与图上实际元素一一对应，没有多余也没有缺失
- [ ] 已确认的信息没有再标"待确认 / 待补录 / 用途未记"
- [ ] 用户要求删除的内容彻底删了（图形 + 所有相关文案 + XML 注释）
- [ ] 同一条信息在卡片 / 区块注释 / 汇总块 / 图例 / 副标题里表述一致
- [ ] 数量统计与实际画出的卡片数吻合（如"共 11 个空置段"就要真有 11 张卡）
- [ ] 数据来源与截止日期已写在标题下方
- [ ] 模板占位符 `【】` 全部替换掉了

### 落盘

- [ ] 存在文档同级 `images/` 目录下
- [ ] 命名符合 `YYYYMMDD-HHMMSS-mmm.svg`
- [ ] 文档用相对路径引用，且路径真实可达（`test -f` 验证过）
- [ ] 临时渲染目录已清理

## 三、常见画面缺陷与成因

| 现象 | 成因 | 修法 |
|------|------|------|
| 文字溢出卡片右边 | 未按 `font-size × 0.55`（ASCII）估算宽度 | 降字号或加宽卡片，重算 pitch |
| 内容溢出区块底边 | 改了子元素高度但没改父容器 height | 父容器 `+Δ`，下方同级元素 `y +Δ` |
| 底部内容被裁 | 元素超出 `viewBox` 高度 | `viewBox` 与白底 rect 高度同步加大 |
| 底部大片空白 | 删了内容但没收缩画布 | 收缩 `viewBox` 与白底 rect |
| 箭头尖插进方框里 | 终点坐标没给箭头留空间 | 终点回退 5~7px |
| 双向线只有一端有箭头 | 缺 `orient="auto-start-reverse"` | 补到 marker 定义上 |
| 箭头和线断色 | marker 的 fill ≠ line 的 stroke | 统一色值 |
| 深色模式下看不见文字 | 缺白底 rect | 补全画布尺寸的白底 rect |
| 中文豆腐块 | 字体栈缺 PingFang SC / Microsoft YaHei | 补全 `font-family` |
| 某排卡片挤在一起 | 卡片宽不一致或 pitch 算错 | 统一卡片宽，重算 `x_i = x0 + i × pitch` |
| 删掉元素后留下空洞 | 只删了元素没重排剩余元素 | 剩余卡片重算 pitch，或相邻区块拉宽占位 |
| 图例有图上不存在的颜色 | 删元素时漏删图例条目 | 同步删图例 |

## 四、改图专项自查

改完已有 SVG，额外过这几条：

- [ ] 改动量 > 5 处或涉及位移时，用了**整文件重写**而不是连续局部替换
- [ ] 重写前**完整读过**当前文件，以文件实际内容为准（不凭记忆）
- [ ] 用 `grep` 确认旧表述零残留（含 XML 注释里的）
- [ ] 一处语义改动，同步改了全部 5 个可能位置：
      卡片文字 / 区块注释 / 汇总块 / 图例 / 分区副标题 / XML 注释
- [ ] 删区块后处理了留下的空白区域
- [ ] 改完重新渲染目视，没有只跑 XML 校验就交付
