# 布局与坐标

SVG 没有自动布局，**每个坐标都要自己算**。这里是算法，照着套就不会溢出、不会压盖。

## 一、动笔前先写坐标表

在写 SVG 之前，把这张表填完（写在草稿里或直接写成 XML 注释）：

```
画布              1960 × ?（高度最后算）
左分区   x=20    y=140  w=920  h=820
  ├ 出口区块     x=40   y=185  w=880  h=140
  ├ 入口区块     x=40   y=345  w=880  h=150
  ├ 网段区块     x=40   y=520  w=880  h=255
  └ 管理区块     x=40   y=795  w=880  h=145
右分区   x=1020  y=140  w=920  h=820   （与左分区对称）
底部汇总 x=20    y=980  w=1150 h=100
图例     x=20    y=1100 w=1920 h=65
画布高 = 图例底边 1165 + 20 = 1185
```

**跳过这一步直接写 XML，返工率接近 100%。**

## 二、等距排列公式

同一排的卡片，**宽度必须一致**，位置用统一步长推：

```
x_i = x0 + i × pitch          （i 从 0 开始）
pitch = 卡片宽 + 间隙
```

排完后必须验算右边界：

```
最后一张右边界 = x0 + (n-1) × pitch + 卡片宽  ≤  容器右边界 - 内边距
```

### 实测可用组合（880 宽的区块内）

| 卡片数 | 卡片宽 | 间隙 | pitch | 起点 | 末张右边界 | 容器右边界 |
|--------|--------|------|-------|------|------------|------------|
| 3 | 272 | 17 | 289 | x0+15 | x0+865 | x0+880 |
| 5 | 160 | 12 | 172 | x0+15 | x0+863 | x0+880 |
| 9 | 86 | 7 | 93 | x0+10 | x0+840 | x0+850 |

一排放不下就换行，**不要为了塞进一排把字号压到 9 以下**。

## 三、容器高度计算

```
容器高 = 最后一个子元素底边 − 容器顶边 + 底部内边距
底部内边距 ≈ 20（有说明文字时 ≈ 25）
```

例：区块顶边 `y=520`，内部最后一行说明文字基线 `y=793`，
则区块高 `= 793 − 520 + 20 = 293`。

### 改高度的连锁反应

某子元素高度 `+Δ` 时，**四个地方一起改**：

1. 该子元素自身 `height +Δ`
2. 父容器 `height +Δ`
3. 父容器内该元素**下方**所有元素 `y +Δ`
4. 若父容器是顶层，画布 `viewBox` 高与白底 rect 高 `+Δ`

漏改第 2、3 步 → 内容溢出边框；漏改第 4 步 → 底部被裁掉。

## 四、文字垂直居中

`<text>` 的 `y` 是**基线**，不是顶边也不是中心。在高 `h`、顶边 `y0` 的矩形里居中：

```
基线 y ≈ y0 + h/2 + font-size × 0.35
```

例：矩形 `y=557 h=68`，字号 12.5 → 基线 ≈ `557 + 34 + 4.4 ≈ 595`。

卡片内多行文字，行距取 `font-size + 6 ~ 8`：

```xml
<rect x="55" y="557" width="160" height="68" rx="6" .../>
<text x="135" y="581" font-size="12.5" font-weight="bold">192.0.2.0/24</text>
<text x="135" y="600" font-size="11">254 个 IP · 业务段</text>
<text x="135" y="618" font-size="10">网关 · 缓存 · 认证</text>
```

水平居中用 `text-anchor="middle"`，`x` 取卡片中心 `= rect.x + width/2`。
同排多张卡片统一用 `<g text-anchor="middle">` 包起来，少写一堆重复属性。

## 五、文字宽度预估（防溢出）

渲染前估算，比渲染后返工便宜：

```
中文字符宽 ≈ font-size × 1.0
数字 / 字母 / 点 / 斜杠 ≈ font-size × 0.55
```

例：`198.51.100.0/24` 共 15 个 ASCII 字符，字号 9.5
→ `15 × 0.55 × 9.5 ≈ 78px`，卡片宽需 ≥ 86（留 8px 内边距）。

**判据：估算宽度 ≤ 卡片宽 − 8。** 超了就降字号或加宽卡片。
中英混排按两类分别累加。

## 六、双栏对称布局

并列的两个大分区（如两个机房），必须严格对称，否则一眼看出歪：

```
画布宽 1960
左分区  x=20    w=920   → 右边界 940
中间留白        80      → 放机房间互联连线，中心 x=980
右分区  x=1020  w=920   → 右边界 1940
两侧页边距各 20
```

两个分区的**内部区块 y 坐标应尽量对齐**（出口区块都在 y=185，入口都在 y=345），
读者可以横向对比。内容量不同导致高度不同时，优先让**上方区块对齐**，差异留到下方吸收。

## 七、连线坐标

### 直线连接两个矩形

```xml
<!-- 从左卡片右边缘到右卡片左边缘，垂直居中 -->
<line x1="300" y1="397" x2="328" y2="397"
      stroke="#607d8b" stroke-width="2" marker-end="url(#arrow)"/>
```

`y` 取两个矩形的共同中心线，`x1` = 左矩形右边界 + 5，`x2` = 右矩形左边界 − 7
（给箭头留出空间，否则箭头尖会插进矩形里）。

### 斜线从上层节点分叉到下层分区

```xml
<line x1="840" y1="80" x2="680" y2="139" stroke="#607d8b" stroke-width="2.5"
      marker-end="url(#arrow)"/>
```

终点 y 落在目标分区顶边 `−1`，让箭头尖正好点在框上。

### 双向互联

```xml
<text x="980" y="522" font-size="11" font-weight="bold" fill="#1565c0"
      text-anchor="middle">机房间</text>
<text x="980" y="537" font-size="11" font-weight="bold" fill="#1565c0"
      text-anchor="middle">VPN 互联</text>
<line x1="944" y1="552" x2="1016" y2="552" stroke="#1565c0" stroke-width="3"
      marker-start="url(#arrowBlue)" marker-end="url(#arrowBlue)"/>
```

标注文字放在线**上方**，两行居中于线的中点。

## 八、图例（必须有）

固定放画布底部，通栏宽度，每行 4 个条目：

```
条目 i 的色块 x = 40 + i × 290
条目 i 的文字 x = 72 + i × 290
行高 26
```

图例条目必须与图上实际出现的元素**一一对应**：
图上没有的颜色不许出现在图例，图上有的必须在图例里能查到。
删了某类元素，图例对应条目同步删。
