# 视觉规范

配色、字号、箭头一律照本文件抄，不要每张图重新发明。同一套语义色跨图复用，
读者看过一张图就认得下一张。

## 一、画布与字体

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1960 1185"
     font-family="-apple-system,'PingFang SC','Microsoft YaHei',sans-serif">
  <rect x="0" y="0" width="1960" height="1185" fill="#ffffff"/>
```

- `viewBox` 定尺寸，**不写** `width` / `height` 属性，让图随容器自适应缩放
- 必须有白底 `rect`，尺寸与 `viewBox` 一致——否则深色模式下文字会看不见
- 字体栈覆盖 macOS（PingFang SC）与 Windows（Microsoft YaHei），保证中文不豆腐块
- 常用画布：双栏全景 `1960 × 按内容算`；单栏 `1200 × 按内容算`

## 三、字号层级

| 层级 | font-size | font-weight | 用途 |
|------|-----------|-------------|------|
| 主标题 | 20 | bold | 图名 |
| 副标题 | 12 | — | 数据来源、截止日期 |
| 外部节点 | 17 | bold | 互联网等 |
| 分区名（机房） | 17 | bold | 🏢 宿迁机房 |
| 分区副标题 | 11.5 | — | 网段范围概述 |
| 功能区块标题 | 14 | bold | 🔥 公网出口 |
| 汇总块标题 | 15 | bold | 🛰 全线下管控枢纽 |
| 卡片主文字（大） | 15 | bold | 公网 IP |
| 卡片主文字（中） | 12.5~13 | bold | 网段号 |
| 卡片次文字 | 11 | — | IP 数量 |
| 卡片第三行 | 9.5~10 | — | 承载业务，空间紧时降到 9.5 |

**层级不要超过 4 档并存**，否则视觉噪音大于信息量。

## 四、箭头 marker

固定三种，放在 `<defs>` 里：

```xml
<defs>
  <marker id="arrow" viewBox="0 0 10 10" refX="9" refY="5"
          markerWidth="7" markerHeight="7" orient="auto-start-reverse">
    <path d="M 0 0 L 10 5 L 0 10 z" fill="#607d8b"/>
  </marker>
  <marker id="arrowBlue" viewBox="0 0 10 10" refX="9" refY="5"
          markerWidth="7" markerHeight="7" orient="auto-start-reverse">
    <path d="M 0 0 L 10 5 L 0 10 z" fill="#1565c0"/>
  </marker>
  <marker id="arrowOrange" viewBox="0 0 10 10" refX="9" refY="5"
          markerWidth="7" markerHeight="7" orient="auto-start-reverse">
    <path d="M 0 0 L 10 5 L 0 10 z" fill="#e65100"/>
  </marker>
</defs>
```

- `orient="auto-start-reverse"` 是双向箭头的前提，必须写
- marker 的 `fill` 要和线的 `stroke` 同色，否则箭头和线断色

### 线型语义

| 关系 | 写法 |
|------|------|
| 一般流向 | `stroke="#607d8b" stroke-width="2" marker-end="url(#arrow)"` |
| 已确认的双向互联 | `stroke="#1565c0" stroke-width="3" marker-start="url(#arrowBlue)" marker-end="url(#arrowBlue)"` |
| 可达范围 / 逻辑关系 | `stroke="#e65100" stroke-width="2" stroke-dasharray="5 4" marker-end="url(#arrowOrange)"` |
| 待确认关系 | 灰虚线 `stroke="#9e9e9e" stroke-dasharray="6 4"`，并在旁标注"待确认" |

**实线 = 已确认，虚线 = 待确认或逻辑关系。** 一旦确认要把虚线改成实线。

## 五、emoji 图标

只用在**分区名和区块标题**，不要撒在卡片里。

| emoji | 用途 |
|-------|------|
| 🌐 | 互联网 / 外部网络 |
| 🏢 | 机房 / 物理站点 |
| 🔥 | 防火墙 / 出口 |
| 🌍 | 公网入口 / DNAT |
| 🖥️ | 服务器网段 |
| ⚙️ | 管理网段 |
| 🧱 | 容器网段 |
| 🛰 | 枢纽 / 管控中心 |
| ★ | 特殊节点强调（纯文本，非 emoji，颜色更可控） |
| ❓ | 待确认 / 待补录 |

强调优先用 `★` 而不是 emoji——`★` 能跟随 `fill` 变色，emoji 不能。
